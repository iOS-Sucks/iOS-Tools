DNS profile generator

Build an install-ready .mobileconfig with managed DNS settings. Presets fill known-good servers; edit freely.

Empty DoH field → plain DNS payload. With a URL → encrypted payload (DNSProtocol: HTTPS).

IPSW / signing lookup
