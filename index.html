02 device identifiers + firmware

UDID / ECID helpers

Classic 40-char hex UDIDs, 24/25-char newer IDs, and ECID hex ⇄ decimal via BigInt.

—

IPSW / signing lookup

No API keys, no tracking — builds the correct ipsw.me deep links for any device identifier.

    bundle ID validator

    Checks reverse-DNS style (com.example.app): each segment starts with a letter, letters/digits/hyphens only, two or more segments. Lowercase recommended by Apple.

    —

    App Store link builder

    Turns the numeric App Store ID (found in App Store Connect or the id123456789 part of a store URL) into a shareable link.

      Luhn / IMEI check

      Validates the checksum in IMEIs (dial *#06# to see yours), payment cards, and other Luhn-coded numbers. Checksum only — it can't tell you if a number is registered or blocked.

      03 dev text + time

      base64

      UTF-8 safe. Decodes strictly — invalid input is reported, not silently mangled.

      —

      JSON formatter

      Validates with JSON.parse, pretty-prints with 2 spaces.

      —

      UUID / time

      crypto.randomUUID() for identifiers, one converter for unix ⇄ ISO-8601.

      —

      —

      plist pretty-printer

      Indents raw plist / mobileconfig XML so diffs are readable. Same formatter the viewer uses.

      —

      plist → JSON

      Converts <dict>/<array> plists to JSON. Dates become ISO strings, <data> becomes base64.

      —

      URL codec

      Percent-encodes with encodeURIComponent; decodes strictly and reports malformed sequences.

      —

      JWT decoder

      Shows header and payload, converts exp/iat to dates. The signature is not verified — never trust a token just because it decodes.

      —

      hasher

      SHA-2 digests via crypto.subtle — needs a secure context (https, localhost, or file). Lowercase hex output.

      —

      color converter

      Accepts #bfff00, bfff00, or rgb(191,255,0) and shows all three forms.

      —

      password generator

      Drawn from crypto.getRandomValues — never Math.random.

      —

      chmod converter

      Unix permission bits both ways. Sticky/setuid bits (1xxx/2xxx/4xxx) not covered — plain rwx only.

      word counter

      Counts as you type — nothing leaves the page.
